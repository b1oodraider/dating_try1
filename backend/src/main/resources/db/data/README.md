# Справочники

`cities_ru.csv`, `city_names_ru.csv` — города России (от 1000 жителей) с русскими, разговорными и историческими
названиями. Источник: [GeoNames](https://www.geonames.org/) (лицензия CC BY 4.0 — в приложении нужна строка
«Данные о городах: GeoNames»). Плюс наши разговорные сокращения («Мск», «Екб», «Нск») в `scripts/build-cities.py`.
Пересборка — см. комментарий в начале скрипта.
