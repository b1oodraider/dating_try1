# Группы по интересам

Код: модуль `com.dating.communities` (сервер), `mobile/lib/features/communities/` (приложение), миграция `040-communities`.
Вкладка «Интересы» в приложении (на месте гачи — гача скрыта: пользовательский API `/gacha` выключен
`app.gacha.enabled=false`, данные и админка остались).

## Как работает

- Группа — сообщество вокруг фильма, книги, сериала, игры, аниме, музыки или «вселенной» (франшизы): название, тип,
  смайлик (вместо обложек — у обложек есть правообладатели), описание, число участников.
- Группы создаёт только персонал (CONTENT_EDITOR / ADMIN: `/admin/communities`, аудит). Пользователи предлагают новые
  («Предложить группу», не больше 5 в день); персонал принимает или отклоняет (`/admin/communities/suggestions`).
- На странице группы — «Подписаться» и «Начать поиск». Поиск ставит в ленте фильтр «только участники этой группы»
  (полоса «Поиск по группе: … ✕» над лентой). В фильтрах ленты — «Общие группы»: выбрать несколько из своих групп,
  показываются люди хотя бы из одной. Остальные фильтры (кто ищет кого, возраст, город, образ жизни) действуют как обычно.
- Группы видны в анкете (раздел «Группы»; общие — с пометкой «у вас тоже») и первыми попадают в «Общее» на карточке.
- Лимита на подписки нет. Удаление аккаунта удаляет подписки и предложения.

Стартовый каталог — 69 групп (миграция 040).
