# Аудит дизайна мобильного приложения (taste-skill, 2026-10-21)

Скилл: `design-taste-frontend` (Leonxlnx/taste-skill), режим «review» для экранов приложения
(`references/app-screens.md` + `references/critique.md`). Его браузерный инспектор и линтер работают только
с вебом (HTML/CSS по URL) — для Flutter они не применимы, поэтому оценка сделана по скриншотам нашего
харнесса (`SCREENSHOT_DIR=… flutter test test/screenshots`, ширина телефона 390, светлая и тёмная темы)
и по коду темы. Цифры ниже — из кода (`app_theme.dart`, grep по `lib/`).

Стиль, который скилл выдал для продукта (`draw.mjs --app --kind community --keep palette`):
**accent-ladder** — один фирменный цвет в полную силу только на мелких метках (главная кнопка, активная
иконка навигации, данные), а площади несут его бледные оттенки. Это ближе всего к тому, что у нас уже есть,
поэтому берём его как направление.

## Критика (формат critique.md §4)

```
ROUND 1 (before)
Seen in one second: фото на карточке ленты и розово-коралловый градиент кнопки «нравится».
Idea (one sentence): «знакомства без спешки» есть в тексте онбординга, но в интерфейсе не видна —
  карточки темпа общения («Не тороплюсь», «Длинные сообщения») спрятаны в самом низу анкеты.
Live thing: свайп карточки (категорийный, как у всех).
Layout words by screen: лента=фото-карточка / симпатии=сетка 2×N / чаты=список / чат=пузыри /
  профиль=карточки-списки / удача=карточки / помощь=список-аккордеон / онбординг=центр.
Scores: design 6 · usability 7.5 · creativity 5.5 · content 7 → overall 6.4
Caps applied: градиенты на кнопках и карточках + тени у элементов в покое → overall ≤ 6.5;
  «экран мог бы быть у любого конкурента» (обложку Tinder/Mamba не отличить) → creativity ≤ 6.
```

## Что видно на скриншотах

**Во всём приложении**
1. **Градиент rose→coral** — на кнопке «нравится», исходящих пузырях чата, шапке «Удачи», плитке-логотипе,
   кольце новых пар, кнопках в «Симпатиях», бейдже «% совпадения» (9 файлов, 13 мест). Для приложений это
   запрещённый приём: градиент на кнопках, карточках и фонах → плоский цвет.
2. **Тени в покое** — «приподнятые» круглые кнопки под карточкой (розовая и серая подложка снизу), плитка
   логотипа. Тень допустима только у того, что парит (меню, шторка, диалог).
3. **Акцент на хроме, а не на смысле.** Розовым залиты: активная вкладка навигации, все выбранные чипы
   (экран фильтров превращается в стену красных плашек), все переключатели, контурные кнопки и их текст,
   иконки в строках профиля, ссылки «Изменить». Акцент перестаёт значить «здесь главное».
4. **Слишком много оттенков.** rose, coral, синий (суперлайк), голубой (галочка «проверен»), золотой
   (премиум, буст), зелёный («опубликована»), оранжевый/фиолетовый/синий (рамки редкости в «Удаче»).
   Ориентир — до 4 на экран, фиолетовый не использовать вовсе.
5. **Шрифт по умолчанию** (Roboto, `fontFamily` не задан) с весом 800 на заголовках — «шрифт кита».
   У продукта нет своего лица.
6. **Мелкие ПРОПИСНЫЕ подписи с разрядкой** в анкете («ИЩУ», «О СЕБЕ», «ИНТЕРЕСЫ», `letterSpacing 1.1`) —
   запрещено; заголовок раздела — обычный регистр, 14–16px, полужирный.
7. **Карточки с розовой заливкой + 1px розовой рамкой + большим радиусом** — одновременно граница и тон,
   плюс контурные кнопки-пилюли той же рамкой. Нужно выбрать одно: тон или граница.

**По экранам**
- **Лента.** Сильная сторона: фото занимает экран, имя крупно. Минусы: бейдж «87% совпадение» —
  градиентная пилюля сверху (читается как рекламная наклейка); три кнопки разных цветов и размеров с тенями;
  в тёмной теме «пропустить» и «суперлайк» — тёмные круги на тёмном фоне, почти не видны.
- **Симпатии.** Сетка 2 колонки при 5 анкетах — пятая карточка остаётся сиротой с пустой половиной ряда.
  На каждой карточке по две кнопки, одна с градиентом — 10 кнопок на экране.
- **Чаты.** «Новые пары» с одним человеком и пустая нижняя половина экрана. Градиентное кольцо вокруг аватара.
- **Чат.** Исходящие пузыри с градиентом; входящие розовые — два розовых тона спорят. Предложение: исходящие
  плоский rose, входящие нейтральный серый.
- **Профиль.** Первый экран перегружен: кольцо заполненности, имя, пилюля статуса, советы и крупная красная
  контурная кнопка «Скрыть анкету» (разрушительное по смыслу действие стоит выше всего). Две кнопки
  «Как видят» / «Заново» той же формы. Лента фото уходит за правый край (обрезанная плитка «добавить»).
- **Удача.** Шапка — градиентная карточка с белой кнопкой; призы — иконки в цветных квадратах и рамки
  трёх разных цветов (включая фиолетовый).
- **Помощь.** Пилюля «ответ» — насыщенно-красная с белым текстом: красный читается как ошибка, а это хорошая
  новость. Статус — бледная пилюля (зелёная или нейтральная) с тёмным текстом.
- **Мастер анкеты.** Неактивная «Далее» — светло-серый текст на сером (≈1.5:1), не видно, почему неактивна.
- **Вход и онбординг.** Всё по центру, нижняя половина экрана пустая, плитка-логотип с градиентом и тенью.

## Три изменения, которые сдвинут больше всего (порядок critique.md §5)

1. **Плоский цвет и дисциплина акцента (accent-ladder).** Убрать все градиенты и тени в покое. Полный rose —
   только на «нравится», главной кнопке экрана, активной иконке навигации и данных (% совпадения, счётчики).
   Площади — бледные тона rose (выбранный чип = бледный фон + тёмно-розовый текст, а не заливка);
   переключатели — нейтрально-тёмные; иконки в списках — серые; контурные кнопки — нейтральная рамка.
2. **Своё лицо через шрифт и шкалу.** Подключить кириллический гротеск со своим характером (Onest или Golos
   UI — оба сделаны под русский), шкала 12/14/16/20/28, вес 600 для заголовков вместо 800, 700 — только имя
   на карточке. Убрать прописные подписи с разрядкой.
3. **Бюджет оттенков и фирменный элемент.** Свести палитру к rose + нейтральные + один статусный зелёный
   (+ золото только для премиума). Суперлайк — звезда в чернилах/rose, «проверен» — та же галочка в одном
   тоне, рамки редкости — бледные тона без фиолетового. Фирменный элемент — то, что есть только у нас:
   **темп общения** (шкала «не тороплюсь ↔ живой чат» из карточек общения) вынести на карточку ленты
   рядом с «Общее», вместо градиентного бейджа совпадения.

Дальше по списку: сирота в «Симпатиях» (одна колонка крупных карточек или подстройка числа колонок),
порядок первого экрана профиля («Скрыть анкету» вниз, в «Видимость»), контраст кнопок в тёмной теме,
читаемая неактивная кнопка с причиной, пилюля «ответ».

## Что не проверено

- Инспектор и линтер скилла не запускались: они только для веба. Измерения (контраст, число размеров
  шрифта, отступы) по Flutter не автоматизированы — оценка по скриншотам.
- Только ширина телефона 390px; планшет и маленькие экраны (320–360) не смотрели.
- На скриншотах шахматные заглушки вместо фото — реальные фото меняют восприятие ленты и «Симпатий».
