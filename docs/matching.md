## 1. Жёсткие фильтры (двусторонние, если не указано иное)
- **Пол:** только М/Ж. Пол кандидата входит в «кого ищу» смотрящего и наоборот.
  Сменить пол — только через поддержку с подтверждением документа.
- **Возраст:** возраст кандидата в диапазоне смотрящего и наоборот. По умолчанию от 18 без верхней границы.
  Храним `birth_date` (ввод маской `ДД.ММ.ГГГГ`, без календаря); наружу — полные годы и, по желанию, знак зодиака.
  Смена даты — через поддержку или раз в год (подсмотреть у конкурентов).
  ⚠️ Проверить, не теряем ли пользователей на шаге «дата рождения» вместо «возраст» (метрика воронки онбординга).
- **Цели знакомства:** мультивыбор; должна пересекаться хотя бы одна цель. «Пока не знаю» совпадает со всеми.
  Не премиум (из `ADVANCED_FILTERS` убрать).
- **Радиус:**
  - Свой радиус — жёсткий; радиус кандидата — мягкий (штраф к счёту, если смотрящий дальше).
  - Кандидат, который уже лайкнул смотрящего, проходит сквозь его радиус (остальные жёсткие фильтры — нет).
  - Анкеты в радиусе закончились — явная кнопка расширения: +10 → +25 → +50 км → весь регион. Без молчаливого расширения.
- **Фильтры-факты** (дети, курение, алкоголь, спорт, животные, карточки-предпочтения из п. 6):
  - По умолчанию «не важно», включаются вручную; у каждого — «показывать и тех, кто не указал».
  - Двусторонние: если A скрыл курящих, курящий B не видит A. Если B не указал и у A включено
    «показывать неуказавших» — B видит A.
  - Какие из них премиальные — решить позже.
- **Верификация:**
  - Неверифицированный не виден в чужих лентах. Может смотреть до 50 анкет в день и лайкать;
    лайки ждут в очереди («отправится после проверки селфи»).
  - Лайк в очереди живёт 24 часа; пока анкета на модерации, срок стоит на паузе.
  - Тестовые аккаунты — исключение.
- **Неактивность:** 30 дней без входа — анкета скрыта из выдачи до возвращения; пуши за 7, 3 и 1 день до скрытия.
- **Исключения:** блок (оба не видят друг друга), «скрыть» (скрытый ничего не теряет, на рейтинг не влияет),
  лайкнутые, пропущенные (п. 4), ограничения модерации, тестовые и настоящие аккаунты раздельно.

## 2. Счёт (мягкое ранжирование)
Сортировки по дате изменения анкеты нет. Потолка у итогового счёта нет (модификаторы складываются).

Базовый счёт:
- **Расстояние внутри радиуса — до 30.** Ближе — больше. Если хоть у одного вместо GPS центр города — фиксированные 15.
- **Общие интересы, музыка, цели — до 25.** Точное совпадение по ID — высокий вес, совпадение категории/жанра — малый;
  бонус за 2+ общие цели.
- **Качество анкеты — до 20.** Фото, текст, поля-факты, карточки.
- **Давность входа — мягкое снижение**, без бонуса за «много свайпов» и часы онлайн:
  −0,15 балла за каждый день без входа (с премиумом −0,1), до отсечения на 30 днях.
- **Рейтинг поведения** — вес и модель не решены (п. 5).

Модификаторы:
- **Входящий лайк:** лайкнувших подмешиваем в ленту в случайных позициях (не постоянная прибавка и не каждая N-я
  карточка), чтобы нельзя было вычислить, кто лайкнул (это премиум-функция).
- **Буст:** +10…15. Не первое место: идеальный кандидат остаётся выше купившего буст.
- **Новичок:** +15 на первые 50–100 показов после верификации.
- **За пределами мягкого радиуса кандидата:** −15…25.
- **Кулдаун показа:** анкета, показанная без свайпа (закрыл приложение), уходит вниз на 2–4 часа,
  чтобы лента не открывалась тем же человеком.

Админка: разбивка счёта по слагаемым для любой пары «смотрящий — кандидат».

## 3. Гео и города
- Разрешил геолокацию — координаты с округлением до ~1 км; запретил — центр выбранного города.
- Наружу только «~N км»; если у кого-то центр города — показываем только город.
- Справочник городов с ID: GeoNames (CC BY 4.0, указать источник) + исторические названия + своя таблица
  разговорных («Питер», «Мск», «Екб»). Подсказки в PostgreSQL (`pg_trgm`), без внешнего поиска.
- Старые текстовые города — перевести поиском; неоднозначные — попросить выбрать при входе.

## 4. Пропущенные и «рефреш»
- Пропущенные не возвращаются сами (срок `app.social.pass-ttl` убрать или сделать бесконечным).
- **Без премиума:** вернуть пропущенных можно, только когда по фильтрам всё закончилось, и не чаще раза в день/неделю (решить).
- **С премиумом:** в любой момент.
- Лайкнутые не возвращаются никогда. Смена фото на это не влияет.

## 5. Рейтинг поведения — не решено
Проблема: человек, случайно попавший в низкий рейтинг, может не выбраться или уйти раньше, чем рейтинг поправится.
Варианты:
- односторонний рейтинг (низкий — штраф у всех, без «болота» низких друг с другом);
- вместо общего рейтинга — отдельные типы нарушений со своими последствиями, а рейтинг — только для
  «неповеденческих» проблем (лайк-спам, санкции модерации);
- гостинг: учитывать или нет; не считать гостингом долгие ответы, если человек заявил медленный темп.
Точно: подтверждённые жалобы — да; обычные блоки и «скрыть» — нет; серийные удаления мэтчей без единого
сообщения — сигнал. В чате — кнопка «Вежливо завершить диалог».

## 6. Карточки общения
**Решено 2026-10-22:** в каждой категории — **один ответ** (кнопки по порядку шкалы, повторное нажатие снимает выбор;
сервер: `400 ONE_TAG_PER_CATEGORY`, миграция 035 оставила по одной карточке — ближайшую к середине шкалы).
Фильтров по карточкам **пока нет**: все описательные — процент совпадения и подсветка общих в анкете («у вас тоже»).
Карточки убраны с карточки ленты — видны в полной анкете, в самом низу. Ниже — исходный замысел.
- **Предпочтения-фильтры** (то, что реально мешает общению): «не люблю голосовые», «предпочитаю живое общение»,
  «сначала пообщаться в сети», «хочу сразу встречу» и т. п. — работают как фильтры-факты (п. 1).
- **Описательные** («люблю много общаться» и т. п.) — не фильтр: только плашка «уровень совпадения» поверх анкеты,
  совпадающие карточки подсвечены.
- Ввод — дискретные кнопки (4–5 позиций) вместо ползунка. Нужна миграция нынешних карточек.
- В UI: в профиле; шпаргалка по стилю собеседника над полем ввода в пустом чате; плашка «отвечает медленно»
  в списке чатов, если человек так указал.

## 7. Поля анкеты
Особые категории ПДн (религия, политика, здоровье, интимное) не собираем (152-ФЗ).

| Поле | Формат | Роль |
|---|---|---|
| Цели знакомства | мультивыбор | жёсткий фильтр (пересечение) + счёт |
| Рост | см | показ + фильтр |
| Дети (есть) | есть / нет | фильтр |
| Дети (планы) | хочу / не хочу / не решил | фильтр |
| Курение | не курю / иногда / курю (вейп, кальян) | фильтр |
| Алкоголь | не пью / редко / умеренно / часто | фильтр |
| Спорт | регулярно / иногда / нет | фильтр |
| Животные | кошка / собака / другое / нет, мультивыбор | фильтр |
| Профессия | короткий текст | показ |
| Образование | уровень из списка + вуз текстом | только показ |
| Языки | мультивыбор из справочника | показ |
| Интересы | закрытый справочник 120–150 тегов в категориях, до 10 | фильтр + счёт по ID и категории |
| Музыка | свой справочник + добор недостающих через API (MusicBrainz), до 5 | фильтр + счёт по ID и жанру |

«Предложить интерес» — заявка на пополнение справочника, не создаёт тег сразу.
