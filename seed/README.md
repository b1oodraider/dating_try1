# Тестовые анкеты (seed profiles)

Папка для массовой загрузки готовых анкет с фотографиями, чтобы у тестовых аккаунтов была наполненная лента.
Скрипт `scripts/seed-profiles.mjs` входит под тестовым номером и через Testing API
(`/api/v1/testing/profiles`, см. [docs/api-contract.md](../docs/api-contract.md), раздел «Testing: seed profiles»)
создаёт каждую анкету: создание (черновик) → загрузка фото по одному → публикация.

**Важно:**

- Каждая анкета — отдельный тестовый аккаунт без телефона: войти в него нельзя.
- Такие анкеты **видны в ленте только тестовым аккаунтам** (`+7 900 000-00-01..03` в dev и в моке).
  Обычный пользователь их не увидит, и тестовые аккаунты не видят обычных пользователей.
- Testing API работает только при `APP_TESTING_ENABLED=true` (в профиле `dev` уже включён) и в мок-сервере.
- Мок-сервер хранит всё в памяти: после его перезапуска анкеты нужно загрузить заново.

## Структура папки

```
seed/
├── README.md                 ← этот файл
├── profiles.example.json     ← пример: 12 анкет (в git)
├── profiles.json             ← ваш список анкет (НЕ в git; если его нет, берётся пример)
└── photos/
    ├── .gitkeep
    ├── 01-anna/              ← папка анкеты = поле "folder"
    │   ├── 1.jpg             ← первое по имени фото становится главным
    │   ├── 2.jpg
    │   └── 3.webp
    ├── 02-maxim/
    │   └── 1.png
    └── ...
```

`profiles.json` и всё содержимое `photos/` (кроме `.gitkeep`) игнорируются git: это ваши личные сгенерированные материалы.

Начать проще всего так: скопировать пример и создать папки под фото.

```powershell
Copy-Item seed\profiles.example.json seed\profiles.json
"01-anna","02-maxim","03-alina","04-dmitry","05-ekaterina","06-artem","07-olga","08-ivan","09-mariya","10-sergey","11-polina","12-ruslan" |
  ForEach-Object { New-Item -ItemType Directory -Force "seed\photos\$_" | Out-Null }
```

### Фото

- Форматы: `.jpg`, `.jpeg`, `.png`, `.webp` (тип проверяется сервером по содержимому файла).
- Не больше 5 МБ на файл (более крупные скрипт пропустит с предупреждением), не больше 6 фото на анкету
  (лишние пропускаются).
- Порядок — по имени файла (`1.jpg`, `2.jpg`, …, `10.jpg` — числа сравниваются как числа). Первое фото — главное.
- Метаданные (EXIF, GPS) сервер удаляет сам.
- Как генерировать фото — на ваше усмотрение (любой генератор изображений; удобно портретное соотношение 4:5 или 3:4).
- Нет папки или в ней нет фото — это не ошибка: анкета будет создана, но останется черновиком (DRAFT)
  и в ленту не попадёт.

## Поля анкеты (`profiles.json` — массив таких объектов)

| Поле | Обязательно | Описание |
|---|---|---|
| `folder` | желательно | Имя подпапки в `seed/photos/` с фото этой анкеты |
| `displayName` | да | Имя, 2–50 символов |
| `age` | да | Возраст, целое число 18–100 |
| `city` | да | Город, 1–60 символов (лента фильтрует по точному совпадению: «Москва», «Санкт-Петербург», …) |
| `aboutText` | нет | «О себе», до 1000 символов |
| `tagCodes` | нет | Карточки общения, до 10 кодов (список ниже) |
| `heightCm` | нет | Рост, 120–230 см; не указывать — анкета без роста |
| `goalCodes` | нет | Цели знакомства, до 3 кодов (список ниже) |
| `dailyStatusText` | нет | «Статус на сегодня», до 200 символов; живёт 24 часа с момента загрузки |
| `premiumDays` | нет | Дней премиума (значок премиума в ленте), 0–3650 |
| `cosmetics` | нет | Коды косметики, до 10; рамки, статусы и обои сразу надеваются |
| `publish` | нет | `false` — оставить черновиком; по умолчанию `true` (публикуется, если загружено хотя бы одно фото) |

Пол в анкете не хранится — он угадывается только по имени.

Пример:

```json
[
  {
    "folder": "01-anna",
    "displayName": "Анна",
    "gender": "FEMALE",
    "seeking": "MALE",
    "age": 27,
    "city": "Москва",
    "heightCm": 168,
    "aboutText": "Продуктовый дизайнер, катаюсь на велосипеде.",
    "tagCodes": ["PACE_FAST_CHAT", "FORMAT_COFFEE_SHORT"],
    "goalCodes": ["SERIOUS_RELATIONSHIP", "DATING"],
    "premiumDays": 30,
    "cosmetics": ["FRAME_STUB_GOLD", "STATUS_STUB_EARLY_BIRD"]
  }
]
```

### Коды карточек общения (`tagCodes`, миграция 002)

| Код | Карточка |
|---|---|
| `PACE_ASYNCHRONOUS` | Темп переписки: Асинхронный ответ |
| `PACE_FAST_CHAT` | Темп переписки: Люблю живой диалог |
| `PACE_LOW_BATTERY` | Темп переписки: Иногда беру паузу |
| `FORMAT_WALK_FIRST` | Первая встреча: Прогулка на воздухе |
| `FORMAT_COFFEE_SHORT` | Первая встреча: Кофе на 30–40 минут |
| `FORMAT_TEXT_BEFORE_MEET` | Первая встреча: Сначала переписка |
| `FORMAT_SHARED_ACTIVITY` | Первая встреча: Совместное занятие |
| `CALLS_TEXT_ONLY` | Звонки и сообщения: Только текст |
| `CALLS_VOICE_WELCOME` | Звонки и сообщения: Голосовые ок |
| `CALLS_PRE_CALL_CHECK` | Звонки и сообщения: Звонок по согласованию |
| `BOUND_NO_SMALLTALK` | Комфорт и темы: Сразу к интересным темам |
| `BOUND_RESPECT_LIMITS` | Комфорт и темы: Без настойчивости |
| `BOUND_DIRECT_COMMUNICATION` | Комфорт и темы: Прямота без намеков |
| `SOC_QUIET_SPACES` | Социальная среда: Тихие места |
| `SOC_DEEP_TALKS` | Социальная среда: Глубокие разговоры |

### Коды целей (`goalCodes`, миграция 008)

| Код | Цель |
|---|---|
| `SERIOUS_RELATIONSHIP` | Серьёзные отношения |
| `FAMILY` | Создание семьи |
| `DATING` | Свидания |
| `FRIENDSHIP` | Дружба |
| `CHAT` | Общение |
| `NOT_SURE` | Пока не знаю |

### Коды косметики (`cosmetics`, миграция 007; все — тестовые заглушки)

| Код | Что это | Видно в ленте |
|---|---|---|
| `FRAME_STUB_GOLD` | Рамка фото «Золотая рамка» (надевается) | да |
| `FRAME_STUB_NEON` | Рамка фото «Неоновая рамка» (надевается) | да |
| `STATUS_STUB_EARLY_BIRD` | Статус профиля «Ранняя пташка» (надевается) | да |
| `STATUS_STUB_BOOKWORM` | Статус профиля «Книжный червь» (надевается) | да |
| `WALLPAPER_STUB_NIGHT` | Обои чата «Ночной город» (надеваются) | нет |
| `WALLPAPER_STUB_SUNSET` | Обои чата «Закат» (надеваются) | нет |
| `STICKERS_STUB_CATS` | Стикеры «Котики» (только владение) | нет |
| `STICKERS_STUB_SPACE` | Стикеры «Космос» (только владение) | нет |

Если указать две вещи одного слота (например, две рамки), надетой останется последняя.

## Запуск (Windows, PowerShell, из корня репозитория)

Нужен Node.js 18 или новее; зависимости не нужны.

### Против настоящего backend (профиль dev, порт 8080)

```powershell
# 1. Backend (в отдельном окне); в профиле dev Testing API уже включён
cd backend
.\gradlew.bat bootRun --args='--spring.profiles.active=dev'

# 2. Проверить папку, ничего не отправляя
node scripts/seed-profiles.mjs --dry-run

# 3. Загрузить (по умолчанию --api http://localhost:8080/api/v1, номер +7 900 000-00-01, код 123456)
node scripts/seed-profiles.mjs

# Перезалить с нуля: сначала удалить все ранее созданные тестовые анкеты
node scripts/seed-profiles.mjs --reset
```

Для другого сервера с `APP_TESTING_ENABLED=true` укажите адрес, тестовый номер и код:

```powershell
node scripts/seed-profiles.mjs --api https://staging.example.com/api/v1 --phone "+7 900 000-00-02" --code 123456
```

### Параметры скрипта

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--api URL` | `http://localhost:8080/api/v1` | Базовый адрес API |
| `--phone PHONE` | `+7 900 000-00-01` | Тестовый номер для входа |
| `--code CODE` | `123456` | Код OTP (если сервер вернул `devMockCode`, используется он) |
| `--dir DIR` | папка `seed` в корне репозитория | Папка с `profiles.json` и `photos/` |
| `--reset` | — | Удалить все ранее созданные тестовые анкеты перед загрузкой |
| `--dry-run` | — | Только проверить файл и фото, ничего не отправлять |
| `--help` | — | Справка |

Как работает скрипт:

1. Читает `profiles.json` (или `profiles.example.json` с уведомлением) и проверяет **все** анкеты до отправки:
   обязательные `displayName`, `gender`, `seeking` (`MALE`/`FEMALE`), `age`, `city`, допустимые значения полей, коды карточек и целей
   (сверяет с `GET /tags` и `GET /goals`). При ошибках ничего не отправляет.
2. Входит под тестовым номером (`/auth/otp/request` → `/auth/otp/verify`) и проверяет доступ к Testing API.
3. Для каждой анкеты: создаёт её → загружает фото по одному → публикует (если `publish` не `false`
   и загружено хотя бы одно фото).
4. Печатает строку по каждой анкете и итог. Ошибка в одной анкете не останавливает остальные;
   код выхода `1`, если хоть одна анкета не загрузилась.

Частые сообщения:

- «не тестовый аккаунт» — номер не входит в список тестовых (`APP_TESTING_TEST_PHONES`).
- «Тестовый API выключен» — сервер запущен без `APP_TESTING_ENABLED=true`.
- «Код для этого номера недавно уже запрашивали, жду N с» — лимит: один код в минуту на номер; скрипт подождёт сам.
- Повторный запуск без `--reset` создаёт анкеты ещё раз (дубликаты).

Посмотреть результат: войти в веб- или мобильном клиенте под тестовым номером (`+7 900 000-00-01..03`, код `123456`)
и открыть ленту.
